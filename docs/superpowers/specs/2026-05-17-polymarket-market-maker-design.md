# Polymarket 自动挂单做市程序 — 设计文档

## 概述

面向不懂代码和服务器的用户，提供一个双击即用的本地 Web 应用，自动在 Polymarket 上进行做市挂单操作。

- **运行形态**：本地 Web 应用，用户双击 exe 启动，浏览器中操作
- **技术栈**：Python + Flask + SQLite
- **打包方式**：PyInstaller 打包为单个可执行文件
- **认证方式**：用户提供钱包私钥，AES 加密本地存储

### 核心模块

1. **Flask Web Server** — 配置界面、状态展示、API 接口
2. **做市引擎** — 每个钱包独立一个线程，执行扫描、挂单、监控
3. **外部交互层** — 封装 Polymarket CLOB API 和 Rewards API 调用
4. **数据层** — SQLite 存储配置、订单历史、成交记录

## 多钱包支持

- 支持导入多个钱包私钥
- 每个钱包独立运行做市引擎线程，互不干扰
- 每个钱包独立判断余额、独立挂单、独立监控成交
- 所有钱包共享同一套策略参数
- 支持单个钱包的启用/禁用（不删除，暂停做市）
- 仪表盘支持"全部启动"和"全部停止"按钮

## 做市引擎详细逻辑

### 1. 市场扫描器（Market Scanner）

定时扫描所有市场，筛选符合条件的市场：

```
获取所有有奖励的市场（Rewards API）
    → 奖励金额 > 阈值（默认 100 USD）
    → 结算日期 > 阈值（默认 4 天后）
    → 获取该市场 orderbook
    → 买一卖一价差 < 阈值（默认 3 美分）
    → 单价在范围内（默认 10~50 美分）
    → min_shares × 挂单价格 ≤ 当前钱包余额
    → 该市场不在冷却期内（同一市场成交后默认 20 分钟冷却）
    → 挂单价格在奖励范围（reward range）内
    → 输出：符合条件的市场列表
```

### 2. 挂单策略（Order Strategy）

根据 orderbook 深度和奖励的 max spread 确定挂单价格位置：

#### 情况一：max spread = 2，价差单位 = 1 美分

| 条件 | 操作 |
|---|---|
| 买一份额 > 2000 | 挂买二价位 |
| 买一份额 ≤ 2000 | 挂买一价位 |

#### 情况二：max spread = 2，价差单位 = 0.1 美分

从买一开始按价位顺序累加份额，找到累计份额 > 6000 的价位，在其下一个价位挂单。

#### 情况三：max spread ≥ 3，价差单位 = 1 美分

| 条件 | 操作 |
|---|---|
| 买一份额 > 2000 | 挂买二价位 |
| 买一份额 ≤ 2000 且 买二份额 > 2000 | 挂买三价位 |
| 买一 + 买二份额 < 2000 且 买三份额 > 2000 | 挂买四价位 |

#### 情况四：max spread ≥ 3，价差单位 = 0.1 美分

从买一开始按价位顺序累加份额，找到累计份额 > 6000 的价位，在其下一个价位挂单。

#### 兜底规则

- 情况一/三（1 美分价差）：如果按顺序找不到符合条件的价位（即所有档位都不满足份额要求），继续往下找直到超出 max spread 为止；超出则跳过该市场
- 情况二/四（0.1 美分价差）：如果累计 > 6000 的下一个价位超出 reward range，跳过该市场

#### 通用规则

- 只挂买单
- 挂单数量 = 奖励要求的 min_shares
- 挂单价格必须在奖励范围（reward range）内，否则不挂
- 允许多个钱包在同一市场挂单

#### 已挂单监管

- 程序持续扫描时，检查已挂买单的价格是否仍在 reward range 内
- 如果不在 reward range 内，自动撤单
- 下次扫描时若该市场仍符合条件，可重新挂单

#### 部分成交处理

- 买单部分成交时：已成交部分立即挂限价卖单 + 启动止损监控
- 未成交部分继续保留挂单等待成交

### 3. 订单监控器（Order Monitor）

持续监控已挂买单的成交情况：

```
检测到买单成交：
    1. 记录成交价格和数量
    2. 立即以成交价挂限价卖单（卖出相同份额）
    3. 启动止损监控
    4. 对该市场启动冷却计时器（默认 20 分钟后才可再次挂单）

止损逻辑：
    - 持续监控持仓的市场最新成交价
    - 若最新成交价 ≤ 买入价 × (1 - 止损比例)
    - 则：撤销限价卖单 → 市价卖出全部持仓

卖单成交：
    - 记录盈利
    - 从持仓列表移除
```

### 4. 停止/关闭行为

当用户点击"停止"（单个钱包或全部停止）或关闭程序时：

- **买单**：自动撤销该钱包所有未成交的买单
- **卖单**：保留不动（让已有持仓的卖单继续挂着等待成交）
- **自动化逻辑**：全部停止（不再扫描、不再挂新单、不再监控止损）

程序关闭前会等待撤单操作完成后再退出。

**停止时提示**：弹窗提醒用户"止损监控已停止，请注意现有持仓风险"。

### 5. 启动恢复逻辑

程序启动时执行状态同步（处理上次非正常关闭的遗留状态）：

1. **残留买单**：自动撤销所有钱包中遗留的未成交买单，从干净状态开始
2. **离线期间成交的买单**：识别出已成交但未处理的持仓，自动为其挂限价卖单（以成交价）并启动止损监控
3. 恢复完成后，再根据用户配置决定是否自动启动做市引擎

## Web 界面设计

### 页面结构（4 个页面）

#### 1. 仪表盘（首页）

- **全局控制**：全部启动 / 全部停止 / 重启引擎 按钮
- **汇总信息**：总余额、总挂单数、总持仓数、总盈亏
- **钱包列表**：每个钱包显示地址（缩写）、余额、活跃挂单数、持仓数、运行状态
- 每个钱包有独立的 启动/停止 按钮
- 点击钱包可查看该钱包详情

#### 2. 配置页面

- **钱包管理**：
  - 钱包列表（地址、余额、状态）
  - 添加钱包（私钥输入，密码框）
  - 删除钱包
  - 启用/禁用开关
- **策略参数**（全局共享）：
  - 最低奖励金额（默认 100 USD）
  - 买卖价差上限（默认 3 美分）
  - 单价范围下限（默认 10 美分）
  - 单价范围上限（默认 50 美分）
  - 最短结算天数（默认 4 天）
  - 止损比例（默认 15%）
- **运行参数**：
  - 市场扫描间隔（默认 30 秒）
  - 成交检查间隔（默认 5 秒）
  - 成交后冷却时间（默认 20 分钟）
- **保存按钮**：点击后持久化参数到数据库
- **未保存提示**：用户修改参数后未保存就切换页面时，弹窗提示"参数已修改但未保存，是否保存？"
- **生效提示**：保存成功后提示用户"参数已保存。如需立即生效，请重启引擎；否则将在下次启动时生效。"

#### 3. 订单管理页面

- **钱包筛选器**：全部 / 选择某个钱包
- **当前挂单列表**：钱包地址、市场名称、价格、数量、挂单时间
  - 每笔挂单有**手动撤单**按钮
  - 支持勾选多笔后**批量撤单**
- **当前持仓列表**：钱包地址、市场名称、买入价、当前价、卖单价格、止损价、浮动盈亏

#### 4. 历史记录页面

- **钱包筛选器**：全部 / 选择某个钱包
- **成交历史表格**：时间、钱包、市场、方向（买入/卖出/止损）、价格、数量、盈亏
- 按日期范围筛选

### 交互细节

- 页面每 5 秒 AJAX 轮询刷新数据
- 关键操作（启动/停止/撤单/删除钱包）有确认弹窗
- 私钥使用 AES 加密存储，加密密钥由用户设置的访问密码派生（PBKDF2）
- 首次启动要求用户设置访问密码

## 可配置参数汇总

| 参数 | 默认值 | 说明 |
|---|---|---|
| 最低奖励金额 | 100 USD | 市场奖励低于此值则跳过 |
| 买卖价差上限 | 3 美分 | 买一卖一差距超过此值则跳过 |
| 单价范围下限 | 10 美分 | 价格低于此值则跳过 |
| 单价范围上限 | 50 美分 | 价格高于此值则跳过 |
| 最短结算天数 | 4 天 | 结算日太近则跳过 |
| 止损比例 | 15% | 跌幅超过此比例则市价卖出 |
| 市场扫描间隔 | 30 秒 | 多久扫描一次新市场 |
| 成交检查间隔 | 5 秒 | 多久检查一次订单成交状态 |
| 成交后冷却时间 | 20 分钟 | 某市场成交后多久才能再挂单 |

---

## 安全设计

- 私钥加密存储：AES-256 加密，密钥由用户密码通过 PBKDF2 派生
- 首次启动强制设置访问密码
- 程序仅监听 localhost，不对外暴露
- 无任何数据上传，所有数据本地存储

---

## 技术依赖

- **Python 3.10+**
- **Flask** — Web 框架
- **py-clob-client** — Polymarket CLOB API SDK
- **SQLite** — 本地数据库（Python 内置）
- **cryptography** — AES 加密
- **APScheduler** 或 **threading** — 后台定时任务
- **PyInstaller** — 打包为 exe
