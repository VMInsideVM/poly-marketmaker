使用说明

把这套程序怎么跑、每个参数是什么意思，一次讲清楚。看不懂的参数保持默认即可，默认值是按经验调好的——唯独「档位模块」没有默认值，必须自己配，不配就不会挂单。

一、这个程序在做什么

它替你在 Polymarket 上做市，目的是赚交易所发的流动性奖励，而不是赌方向。做法是：在符合条件的市场里，按规则挂买单提供流动性，奖励按你挂单的金额和贴近盘口的程度分配。一旦买单成交、手上有了仓位，程序再按离场规则把仓位卖掉。

整个过程不需要你盯盘：填好钱包私钥、设好参数、点开始，程序就会自己循环扫描、挂单、看守、离场。

二、整套运行逻辑

1. 登录与钱包

第一次打开要设一个登录密码，私钥用这个密码加密后存在本地（AES-256-GCM）。之后每次启动都要先登录，因为解密私钥的钥匙只存在内存里，关掉程序就没了，所以程序不会开机自动跑，必须先登录。

你只需填签名私钥，程序会自动推算出对应的存款钱包地址（Polymarket 的 Safe 地址，真正持有资金的那个），不用手填。

2. 扫描发现市场

程序拉取 Polymarket 当前所有发奖励的市场，先按你在配置里勾选的做市品类白名单过滤（默认做除体育/电竞/天气外的全部，含「其他/未分类」），再用几道门槛筛：

  • 市场日均奖励池要够大（最低奖励金额）。
  • 市场的最低挂单份数必须恰好等于你启用的某个档位模块的档位值，否则这个市场不做（详见下面「档位模块」一节）。

发现是所有钱包共用的，每隔一段时间（默认 4 小时）重新发现一次；下单则更频繁。

3. 选品过滤

发现出来的市场，再按每个钱包绑定的模板逐一过滤：买卖价差不能太宽、当前价要落在你设的单价区间内、距离结算不能太近、这个市场对这个钱包不在冷却期。过了这些才进入挂单。

4. 断层单档挂买单

对每个合格市场，程序在买单簿奖励区间内，按相邻价位的最大价差把整个市场归到三级之一（宽断层 / 中断层 / 密盘），再从买一往下挑出第一个「风险系数超过该级门槛」的价位，只挂一单。挂几份由该市场对应的档位模块决定（可以大于市场最低份数）。竞争越小的市场（你能分到的奖励份额越大）越优先下单。整个市场的投入受「单市场最大敞口」和「最大份数」两道闸限制，多个市场同时做也有数量上限。详见下面参数里的「断层单档选档规则」。

5. 看守与离场

挂上买单后，看守线程每隔几秒做一轮检查：

  • 成交检测：买单一旦成交就记冷却、撤掉这笔买单的剩余量。
  • 结算保护：一旦有人在 UMA 上对某市场提交结算（该市场随时会定为 0 或 1），立刻撤掉这个市场你所有的买单，避免在结算前被成交、接到要归零的份额。
  • 离场卖出：手上每个仓位维持一笔卖单，按两段式规则定价（见下面「离场逻辑」一节）。
  • 买单收敛：盘口变动后，把现有买单收敛到最新的目标档位（价不对或量不对的撤掉重挂）。
  • 跌出撤单：某市场不再符合条件了，把它上面的买单整体撤掉（持仓仍正常卖出）。
  • 单侧暂停：某个方向已经有仓位了，就只暂停这个方向继续挂买单，另一个方向照常。

重要：止损看守只在引擎运行时有效。停止引擎会撤掉买单、同时停掉看守线程，已有仓位就不再受止损保护。想让止损一直守着，引擎要保持运行。

6. 自动 / 手动两种模式

自动：点「全部启动」后，程序自己循环扫描、下单、看守，不用管。手动：扫描、下单、启动看守分成几个按钮，你一步步自己来，适合想看清每一步的时候。

7. 每个钱包单独配代理

可以给每个钱包填一个 HTTP 代理，填好后这个钱包的所有网络请求都从对应代理 IP 出口，实现按钱包的 IP 隔离。代理连不上时这个钱包本轮会跳过，绝不改用真实 IP 直连。留空就是直连。

8. 自动更新

启动时会检查 GitHub 上有没有新版本，有就提示你下载、校验、静默安装并重启。

档位模块（决定「做哪些市场」和「挂几份」）

Polymarket 每个奖励市场都规定了一个最低挂单份数（20 份、50 份、100 份……），这个数字直接决定了做这个市场的最小本钱和风险。所以挂单参数不是全局一套，而是按最低份额分档配置：

  • 一个模块 = 一个档位值 + 这个档专属的一套参数。在「配置 → 档位模块」里点「+ 添加档位」，填档位值（比如 20），设挂单份数，再配这一档的三个选档门槛、三个高位系数和门槛、金额数值表。
  • 精确匹配，不做区间也不四舍五入：市场的最低份额必须恰好等于某个已启用模块的档位值才会做。启用了 20 档和 50 档，那么最低份额 30 的市场就完全不碰。
  • 挂单份数可以大于档位值：档位值 20、份数填 40，就是在最低份额 20 的市场上挂 40 份（挂得多，奖励份额也大，占用资金相应变多）。份数不能小于档位值，否则拿不到奖励资格。
  • 份数不影响选档：算风险系数时分母用的是市场自己的最低份数，不是你配的份数。份数只决定「挂多少」，不改变「挂在哪一档」。
  • 停用某个模块（取消勾选）＝ 不再做这个档位的市场；下一轮下单时，这些市场上已挂的买单会被整体撤掉（持仓照常卖出）。

没有任何已启用模块能对上的市场，扫描阶段就不会进入合格列表，下单阶段还有第二道拦截。如果一个档位都没配，程序不会挂任何单——仪表盘顶部会持续提示你去配。

断层单档选档规则

这是怎么在一个市场里挑出「挂哪一档」的地方，也是策略的核心，慢点看。

  • 分级看全簿，挂单只在奖励区间内：给市场分级（下面第三条）时看整个买单簿，包括奖励区间外的价位——区间下方的深坑正是要防的东西，只看区间内就看不见它。真正能挂单的价位仍只限奖励区间内。
  • 风险系数：某个价位的风险系数 = 该价位盘口挂单量 ÷（这个市场的最低份数 × 金额数值）。金额数值来自该市场对应档位模块里的「金额数值表」，按价格档配（价越高数值越大），价超表的档直接不挂。
    例：最低份数 20，某档价 0.25、盘口挂了 60 张、金额数值 1.5，则风险系数 = 60 ÷（20 × 1.5）= 2.0。价越高分母越大，同样盘口算出的系数越低（越贵的价位要更厚的盘口才够格）。
  • 先给市场分级：看整个买单簿相邻价位的最大价差——>「宽断层阈值」归规则1（宽断层）、≥「中断层阈值」归规则2（中断层）、更小归规则3（密盘）。宽 / 中断层阈值是模板全局的，所有档位共用。
  • 再选一档：用所属级别的「选档系数门槛」（取自该市场对应的档位模块），从买一往下取第一个「风险系数 > 该门槛」的价位，只挂这一档、挂该模块配置的份数；没有任何档过门槛就整个市场不挂。
  • 高位厚度闸门：选档之前先看「断层上方到买一」这一段的风险系数之和够不够。三级各有自己的门槛（在档位模块里配），不够就整个市场不挂。规则1 默认 20；规则2、规则3 默认 0，0 表示不设这道闸。

想看某个市场实际会怎么判，去「市场发现」页点「展开」——预演会显示它归到哪一级、每档的系数、选中哪一档、挂几份，不挂的话也会给出原因。

四、引擎参数（全局，所有钱包共用）

在「配置 → 引擎参数」里改，影响整体节奏。

参数默认含义
扫描间隔30 秒自动模式下两轮下单之间隔多久。
成交检测间隔5 秒看守线程多久检查一次成交和离场。
冷却时间20 分钟某市场对某钱包成交后，这段时间内不再对它挂新买单。
奖励缓存时间600 秒奖励数据缓存多久，减少重复请求。

每品类扫描页数上限20 页每个品类最多翻多少页奖励市场（每页 100 个）。调小会加快扫描但可能漏掉大品类里的市场。

五、离场逻辑（卖出怎么定价）

手上每个仓位都维持一笔卖单，成本价是从你真实的链上成交记录加权算出来的（不是交易所给的均价，那个会抽风）。算不出成本时程序宁可跳过、不乱卖，并在监控页标红提醒。两种情况都绝不会以低于成本的价格卖出，唯一的认亏出口是下面的强平兜底：

  • 成本不高于买一价（盈利）：挂在卖一价做被动挂单，等买家以卖一价来吃，尽量多赚一点价差，而不是立刻按买一价甩掉。卖一高于买一、买一又不低于成本，所以这笔单不会亏本成交。
  • 成本高于买一价（保本或套牢）：挂在成本价被动等回本，绝不挂在成本下方亏本卖；只有当亏损（成本减买一）达到「止损线」时，才市价清仓止损以防极端套牢一直扛单。止损线可在「配置 → 策略参数」里设，按比例（默认亏到成本的 20%）或按固定金额（几美分）二选一。

另外还有一道硬底线：任何挂卖单的价格都强制不低于成本价，即便盘口出现异常报价也挂不穿。除了上面的强平，程序不会以低于成本的价格主动挂卖。

六、几个要记住的点

  • 不配档位模块就一单都不挂。这是刻意的：挂几份、什么盘口才挂，必须由你按最低份额分档决定。仪表盘顶部会提示哪些模板还没配。
  • 停止引擎会停掉止损看守，已有仓位失去保护。想止损一直生效就别停引擎。
  • 余额在每次下单前都重新读，避免并发成交导致超额。
  • 参数改完，下次启动引擎才生效（已在运行的需要重启）。
  • 监控页出现「裸奔」字样，说明某仓位暂时没有卖单保护（通常是成交记录还没同步，下一轮会自愈），留意一下即可。
